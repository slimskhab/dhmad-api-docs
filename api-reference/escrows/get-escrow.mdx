title: Get Escrow

<Endpoint method="GET" path="/api/v1/escrows/:id" />

Get detailed information about a specific escrow, including **contract signature status** (whether the seller and buyer have signed the contract). Only accessible if you created the escrow or your associated user account is the seller or buyer.

A [charge](/api-reference/charges/overview) id returns **404** (`Escrow not found. Use GET /v1/charges/:id for charges.`). Use [Get Charge](/api-reference/charges/get-charge) instead.

<RequestExample>
```bash cURL
curl -X GET https://dhmad.tn/api/v1/escrows/507f1f77bcf86cd799439011 \
  -H "Authorization: Bearer sk_live_your_api_key_here" \
  -H "Content-Type: application/json"
```

```javascript JavaScript
const response = await fetch('https://dhmad.tn/api/v1/escrows/507f1f77bcf86cd799439011', {
  method: 'GET',
  headers: {
    'Authorization': 'Bearer sk_live_your_api_key_here',
    'Content-Type': 'application/json'
  }
});

const data = await response.json();
```

```python Python
import requests

headers = {
    'Authorization': 'Bearer sk_live_your_api_key_here',
    'Content-Type': 'application/json'
}

response = requests.get(
    'https://dhmad.tn/api/v1/escrows/507f1f77bcf86cd799439011',
    headers=headers
)

data = response.json()
```
</RequestExample>

## Path Parameters

<ParamField path="id" type="string" required>
  The escrow ID
</ParamField>

## Response Fields

<ParamField response="escrow.id" type="string">
  Unique identifier for the escrow
</ParamField>

<ParamField response="escrow.title" type="string">
  Escrow title
</ParamField>

<ParamField response="escrow.amount" type="number">
  Commercial face amount in `currency`. On progressive-release escrows this is the
  **remaining** float (decremented by releases), not the original funded
  principal — use `fundedAmount` for the stable deal size.
</ParamField>

<ParamField response="escrow.amountTnd" type="number">
  Ledger TND remaining (same remaining-float semantics as `amount` on progressive
  escrows). Fees and payouts settle in TND.
</ParamField>

<ParamField response="escrow.currency" type="string">
  Face currency: `TND`, `USD`, or `EUR`
</ParamField>

<ParamField response="escrow.fxRateUsed" type="number">
  Locked TND-per-1-face-unit rate for this escrow (`1` when `currency` is `TND`)
</ParamField>

<ParamField response="escrow.escrowFee" type="number">
  Platform escrow fee in TND (paid by the party in `feeBearer`)
</ParamField>

<ParamField response="escrow.feeBearer" type="string">
  Who pays platform and developer fees: `"seller"` or `"buyer"`
</ParamField>

<ParamField response="escrow.buyerFundingTnd" type="number">
  Amount the buyer must fund in TND. Equals deal amount when `feeBearer` is `"seller"`; deal amount plus fees when `"buyer"`.
</ParamField>

<ParamField response="escrow.adjustments" type="array">
  Optional history of post-funding monetary adjustments (`add_funds` /
  `refund_funds`), including amounts and fee deltas. Empty or omitted when none
  have occurred. See checkout actions `add_funds` and `refund_funds`.
</ParamField>

<ParamField response="escrow.progressiveRelease" type="object">
  Present only on [progressive-release](/guides/progressive-release) escrows.
  Echoes `enabled: true` (response-only; do not send this on create),
  `autoApproveHours` (client review window), `minReleaseTnd`, and
  `buyerConsentAcceptedAt` (when the client accepted automatic release).
</ParamField>

<ParamField response="escrow.reservedTnd" type="number">
  Progressive release only. Balance claimed by open payout requests — pending,
  approved-but-unpaid, and disputed all reserve. These funds cannot be refunded
  or cancelled while claimed. Forced to `0` on terminal status.
</ParamField>

<ParamField response="escrow.availableForReleaseTnd" type="number">
  Progressive release only. What a new payout request may claim
  (`amountTnd` − `reservedTnd` while open). Zero means the contract needs a
  top-up, or the escrow is terminal.
</ParamField>

<ParamField response="escrow.releasedTotalTnd" type="number">
  Progressive release only. Cumulative TND paid out through partial releases.
</ParamField>

<ParamField response="escrow.reserved" type="number">
  Progressive release only. Open reservations in escrow face currency (same as
  `currency`). Prefer this over inventing `reservedTnd / fxRateUsed`.
</ParamField>

<ParamField response="escrow.availableForRelease" type="number">
  Progressive release only. Claimable balance in face currency. `0` on
  `completed` / `cancelled`.
</ParamField>

<ParamField response="escrow.releasedTotal" type="number">
  Progressive release only. Cumulative face amount paid out through partial
  releases (sum of slice `amountFace` values).
</ParamField>

<ParamField response="escrow.fundedAmount" type="number">
  Progressive release only. Stable funded principal in face currency (original +
  add_funds − unused refunds). **Not** decremented by releases.
</ParamField>

<ParamField response="escrow.fundedAmountTnd" type="number">
  Progressive release only. Stable funded principal in TND.
</ParamField>

<ParamField response="escrow.remainingAmount" type="number">
  Progressive release only. Live remaining float in face currency; forced to
  `0` on `completed` / `cancelled` even if leftover still sits on the document
  after close.
</ParamField>

<ParamField response="escrow.remainingAmountTnd" type="number">
  Progressive release only. Live remaining float in TND; `0` on terminal status.
</ParamField>

<ParamField response="escrow.refundedTotal" type="number">
  Progressive release only. Face amount returned unused
  (`fundedAmount − remainingAmount − releasedTotal`).
</ParamField>

<ParamField response="escrow.refundedTotalTnd" type="number">
  Progressive release only. TND returned unused
  (`fundedAmountTnd − remainingAmountTnd − releasedTotalTnd`).
</ParamField>

<ParamField response="escrow.releaseRequests" type="array">
  Progressive release only. Every billing period with its status
  (`pending`, `approved`, `disputed`, `released`, `voided`), `amountTnd`,
  `amountFace`, `currency`, `approvalDeadline`, `sellerNetTnd`, and any admin
  `resolution`. See
  [List Payout Requests](/api-reference/escrows/list-release-requests).
</ParamField>

<ParamField response="escrow.status" type="string">
  Current escrow status (`pending`, `paid`, `delivered`, `completed`, `cancelled`, `disputed`)
</ParamField>

<ParamField response="escrow.seller" type="object">
  Seller user object with _id, email, firstName, lastName
</ParamField>

<ParamField response="escrow.buyer" type="object|null">
  Buyer user object if buyer exists, otherwise `null`
</ParamField>

<ParamField response="escrow.estimatedDeliveryDays" type="number">
  Legacy optional delivery estimate when present. Not used by platform enforcement; omit for new integrations.
</ParamField>

<ParamField response="escrow.paidAt" type="string|null">
  ISO 8601 timestamp when payment was made, or `null` if not paid
</ParamField>

<ParamField response="escrow.deliveredAt" type="string|null">
  ISO 8601 timestamp when service was delivered, or `null` if not delivered
</ParamField>

<ParamField response="escrow.completedAt" type="string|null">
  ISO 8601 timestamp when escrow was completed, or `null` if not completed
</ParamField>

<ParamField response="escrow.cancelledAt" type="string|null">
  ISO 8601 timestamp when escrow was cancelled, or `null` if not cancelled
</ParamField>

<ParamField response="escrow.createdAt" type="string">
  ISO 8601 timestamp when escrow was created
</ParamField>

<ParamField response="escrow.updatedAt" type="string">
  ISO 8601 timestamp when escrow was last updated
</ParamField>

<ParamField response="escrow.mode" type="string">
  Escrow mode: `standard` (contract + sign + pay + complete; deliver optional) or `quick` (no contract; pay + buyer `complete`; deliver optional). See [Escrow Modes](/api-reference/escrows/overview#escrow-modes). Merchant checkout is a [charge](/api-reference/charges/overview), not a mode.
</ParamField>

<ParamField response="escrow.completionDeadlineDays" type="number">
  Days after deliver before silence auto-releases funds. Integer **3–14**, frozen at creation (default **7**).
</ParamField>

<ParamField response="escrow.completionDeadline" type="string|null">
  ISO 8601 deadline set when the seller delivers (`deliveredAt + completionDeadlineDays`). `null` until deliver.
</ParamField>

<ParamField response="escrow.expiresAt" type="string">
  ISO 8601 timestamp when the escrow expires (pending acceptance)
</ParamField>

<ParamField response="escrow.createdViaThirdParty" type="boolean">
  Whether the escrow was created via the API (third-party application)
</ParamField>

<ParamField response="escrow.createdByApplicationName" type="string">
  Name of the application that created the escrow (when created via API)
</ParamField>

<ParamField response="escrow.disputeTicketId" type="string|null">
  ID of the linked dispute support ticket, or `null` when no dispute ticket exists
</ParamField>

<ParamField response="escrow.disputeTicket" type="object|null">
  Summary of the linked dispute ticket (status, subject, preview reason); present when `disputeTicketId` is set
</ParamField>

<ParamField response="escrow.signatures" type="object|null">
  Contract signature status. Indicates whether the seller and buyer have signed the contract. `null` when no contract exists for this escrow.
</ParamField>

<ParamField response="escrow.signatures.sellerSigned" type="boolean">
  Whether the seller has signed the contract
</ParamField>

<ParamField response="escrow.signatures.sellerSignedAt" type="string">
  ISO 8601 timestamp when the seller signed (present when `sellerSigned` is true)
</ParamField>

<ParamField response="escrow.signatures.buyerSigned" type="boolean">
  Whether the buyer has signed the contract
</ParamField>

<ParamField response="escrow.signatures.buyerSignedAt" type="string">
  ISO 8601 timestamp when the buyer signed (present when `buyerSigned` is true)
</ParamField>

<ParamField response="escrow.signatures.isFullySigned" type="boolean">
  Whether both parties have signed the contract
</ParamField>

<ParamField response="escrow.signatures.signedAt" type="string">
  ISO 8601 timestamp when both parties signed (present when `isFullySigned` is true)
</ParamField>

<Info>
  When no contract exists for the escrow yet, `signatures` is `null`. Use `sellerSigned`, `buyerSigned`, and `isFullySigned` to check contract signing status without calling the contract endpoint.
</Info>

## Error Responses

### 400 Bad Request

**Invalid Escrow ID**

```json
{
  "error": "Invalid escrow ID"
}
```

### 403 Forbidden

**Not Your Escrow**

```json
{
  "error": "Forbidden",
  "message": "You do not have access to this escrow. You can only view escrows where you are the seller or buyer."
}
```

### 404 Not Found

**Escrow Not Found**

```json
{
  "error": "Escrow not found"
}
```

This error occurs if the escrow ID doesn't exist, or if the id is a [charge](/api-reference/charges/get-charge) (`Use GET /v1/charges/:id for charges.`).

---

<Info>
  You can only access escrows where your associated user account is the seller or buyer. If you try to access an escrow you're not involved in, you'll receive a 403 Forbidden error.
</Info>
