<Endpoint method="GET" path="/api/v1/disputes" />

Returns the [disputes you see](/api-reference/disputes/overview#which-disputes-you-see) (charge disputes, chargebacks and escrow disputes on your sales), the one with the most recent activity first. Each dispute has the fields of [Get Dispute](/api-reference/disputes/get-dispute) except `messages`: fetch a dispute to read its thread.

Needs an API key with Disputes access (Read). See [Permissions](/guides/api-keys#permissions).

To keep your own copy in sync, call it with `updatedSince` set to the time of your last sync, or subscribe to the [`dispute.*` webhooks](/guides/webhooks#disputeopened).

<RequestExample>
```bash cURL
curl "https://dhmad.tn/api/v1/disputes?status=open&updatedSince=2026-11-14T00:00:00Z&limit=50" \
  -H "Authorization: Bearer sk_live_your_api_key_here"
```

```javascript JavaScript
const params = new URLSearchParams({
  status: 'open',
  updatedSince: '2026-11-14T00:00:00Z',
  limit: '50'
});

const response = await fetch(`https://dhmad.tn/api/v1/disputes?${params}`, {
  headers: { 'Authorization': 'Bearer sk_live_your_api_key_here' }
});

const { disputes, pagination } = await response.json();
```

```python Python
import requests

response = requests.get(
    'https://dhmad.tn/api/v1/disputes',
    headers={'Authorization': 'Bearer sk_live_your_api_key_here'},
    params={'status': 'open', 'updatedSince': '2026-11-14T00:00:00Z', 'limit': 50},
)

disputes = response.json()['disputes']
```

## Query Parameters

<ParamField query="kind" type="string">
  Only one kind: `charge_dispute`, `chargeback` or `escrow_dispute`.
</ParamField>

<ParamField query="status" type="string">
  Only one status: `open`, `under_review` or `closed`.
</ParamField>

<ParamField query="chargeId" type="string">
  Only the disputes on one charge: its DHMAD id or your `merchantReference`. An unknown charge returns an empty list, not a 404.
</ParamField>

<ParamField query="updatedSince" type="string">
  Only disputes that changed at or after this time (ISO 8601 with a time zone, for example `2026-11-14T00:00:00Z`): a new message or line on the thread, or a change to the dispute's charge, escrow or chargeback (a deadline, an outcome). A dispute whose charge changed for another reason can come back too: compare it with what you stored.
</ParamField>

<ParamField query="page" type="number" default="1">
  Page number.
</ParamField>

<ParamField query="limit" type="number" default="20">
  Disputes per page, up to 100.
</ParamField>

## Response Fields

<ParamField response="disputes" type="array">
  The disputes, newest activity (`lastActivityAt`) first, without `messages`. See [the dispute object](/api-reference/disputes/get-dispute#the-dispute-object).
</ParamField>

<ParamField response="pagination" type="object">
  `page`, `limit`, `total` (disputes matching the filters) and `pages`.
</ParamField>

## Errors

Errors carry the code in `error` and `code`, with a readable `message`.

| Status | Code | Meaning |
|---|---|---|
| 400 | `VALIDATION_ERROR` | A query parameter is not valid (for example `updatedSince` without a time zone); `details` names it |
| 403 | `API_KEY_PERMISSION_REQUIRED` | The key has no Disputes access. See [Permissions](/guides/api-keys#permissions) |
